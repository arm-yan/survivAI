## E8 (pin P08; Reddit R6): price for a 30% margin (Price Calculator reverse mode, C31)
Inputs: unit cost $10.00, your shipping cost $5.00, shipping charged $5.00, target margin 30%, no Offsite Ad
Fixed per order = listing $0.20 + processing fixed $0.25 + unit cost $10.00 + shipping cost $5.00 = $15.45
Variable share = transaction 6.5% + processing 3% = 9.5%
Order total needed = $15.45 / (1 - 9.5% - 30%) = $15.45 / 0.605 = 25.5372
Item price = 25.5372 - shipping charged $5.00 = 20.5372 -> rounded up $20.54
Check at $20.54: order total $25.54; fees $0.20 + $1.66 + $1.02 = $2.88; profit $25.54 - $2.88 - $15.00 = $7.66; margin 30.0%

## E9 (pin P10; Reddit R7): when does a Shopify Basic plan pay for itself? ($25 item + $5 shipping)
Etsy fees per order (E1) = $3.30
Shopify fees per order before plan = 2.9% x $30.00 + $0.30 = $1.17
Saved per order on Shopify = $3.30 - $1.17 = $2.13
Orders a month to cover Basic (monthly billing) = $27.00 / $2.13 = 12.68 -> rounded up 13
Leaves out the cost of bringing your own traffic to Shopify (ads, apps, theme). A floor, not a promise.
